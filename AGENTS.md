# Instructions for Autonomous Agents

1. Read `PROJECT_BRIEF.md` before starting any task or phase.
2. Strictly obey Global Rules G1–G13 at all times.
3. Work on ONE phase at a time and STOP when that phase is completed. Never start the next phase early.
4. Record all architectural and methodological decisions in `docs/DECISIONS.md`.
5. Ensure no target leakage: student split first, transformers fitted inside CV folds, outcome items (A1-A3) excluded from features.
6. Write `docs/phase_reports/phase_NN.md` at the end of each phase following the required format.
7. Provide the final response strictly in the G13 format:
   - (1) What was done
   - (2) Files created or modified
   - (3) Key numbers read directly from output files
   - (4) Checks executed with explicit PASS/FAIL status
   - (5) Risks or decisions logged
