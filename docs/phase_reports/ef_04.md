# EF-04 Phase Report: Synthetic Survey Data

## Outcome

The configuration-driven Environmental & Financial synthetic survey generator
is implemented on `environmental-chamodya`. It creates reproducible
Google-Forms-style raw exports, feature-only upload examples, isolated hidden
synthetic truth, and six branded EDA figures. The CLI exposes
`make-sample-data`.

The selected calibration setting was signal strength 3.10. On the 1,200 base
rows, at-risk prevalence is 27.00%, five-fold LightGBM ROC-AUC is 0.7977, and
Logistic Regression ROC-AUC is 0.8121. The first calibration iteration at
signal strength 3.00 was rejected because LightGBM ROC-AUC was 0.7702; the
second passed all configured gates. Labels are now computed from the same
rounded score written to the export, so the binary outcome is consistent with
the configured threshold of 60.

## Work completed

## Scope and limitations

All records are synthetic. Calibration on data generated from this same design
validates the pipeline, not expected real-world predictive performance. The
hidden file is synthetic EF-7 evaluation truth and must never be treated as a
predictor. No real survey performance, fairness, prevalence, or individual
student conclusion is claimed.
