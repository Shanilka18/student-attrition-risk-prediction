## 3. Four Canonical Derived Indices (0–1 Scale)

1. **Financial Stress Index:**
   $$\text{Financial Stress} = \text{mean}\left(\text{income}_{\text{rev}}, \text{aid}_{\text{norm}}, \text{family\_duty}, \text{cost\_diff}_{\text{norm}}, \text{shock}_{\text{norm}}, \text{worry}_{\text{norm}}, \text{hours}_{\text{norm}}\right)$$
2. **Commute Burden Index:**
   $$\text{Commute Burden} = 0.0 \quad \text{if online learner}, \quad \text{else} \quad \text{mean}\left(\text{time}_{\text{norm}}, \text{spend}_{\text{norm}}, \text{mode}_{\text{mapped}}\right)$$
3. **Digital Access Gap Index:**
   $$\text{Digital Gap} = \text{mean}\left(\text{internet}_{\text{norm}}, \text{device}_{\text{mapped}}, \text{mobile\_data}_{\text{norm}}\right)$$
4. **Study Environment Pressure Index:**
   $$\text{Study Pressure} = \text{mean}\left(\text{quiet\_place}_{\text{norm}}, \text{living\_situation}_{\text{mapped}}\right)$$

## 4. Codec & Format Tolerance

The `EnvFinCodec` class in `src/preprocessing/codec.py` provides bidirectional conversion and handles:
- Case-insensitivity (e.g. `strongly agree` $\leftrightarrow$ `Strongly agree`).
- Unicode dashes (`–`, `—`, `−` $\leftrightarrow$ `-`).
- Currency notations (`LKR 25,000` $\leftrightarrow$ `25000`).
- Structural N/A states (`Not applicable (I study fully online)` $\rightarrow$ code `-2`, pressure `0.0`).
- Informative missingness (`Prefer not to say` $\rightarrow$ code `-1`, pressure `NaN`).
