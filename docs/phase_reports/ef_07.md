# EF-07 Phase Report: Fold-Fitted Risk Profiles

## Outcome

Implemented candidate clustering, deterministic original-scale profile
naming, fold-fitted profile features, generated-data type recovery, and a
paired classifier ablation. Work remains on `environmental-chamodya`; no
merge to `main` was performed.

## Work completed

- Added KMeans, full/diagonal Gaussian Mixture, and Ward agglomerative
  candidates over `k=2..6`, with separation metrics, GMM BIC, and 30-resample
  bootstrap stability.
- Added the configured silhouette eligibility and stability-first selection
  rule, deterministic centroid-derived names, and a training-fold-only
  `ProfileFeatureTransformer`.
- Added one-hot ids, GMM soft membership when selected, distance to assigned
  centre, and high-pressure-index count as optional model features.
- Added the `python -m efi.cli profiles` workflow, model and feature-table
  persistence, generated-only hidden-type recovery, six profile figures, and
  a fixed Logistic Regression / LightGBM ablation across EF-06 folds.
- Updated the project brief and decisions log to describe the optional
  profile-feature ablation.
- Documented the method, generated-data results, limitations, viva Q&A, and
  plain-language explanation in `docs/06_risk_profiles.md`.

## Recorded generated-data run

- Selected KMeans with `k=2` (silhouette `0.261`, mean bootstrap stability
  ARI `0.859`).
- Original-scale centroid naming: **Digital access gaps** and **Several
  pressures at once**.
- Hidden-type recovery (valid only for generated data): 941 matched records,
  ARI `0.100`, NMI `0.094`.
- Logistic Regression completed 15 folds. `agg_profiles` changed mean F1 by
  about `+0.0012`, ROC-AUC by `-0.0032`, and MCC by `+0.0023` versus `agg`;
  this is a small, mixed change. `profiles_only` was weaker on all three
  metrics.
- Paired Wilcoxon p-values are stored in the run summary. Because repeated
  folds overlap, they are reported as descriptive.
- LightGBM was unavailable: its local Windows native library raised an
  access violation on the first fit. It has no reported ablation metrics.
- The run wrote the profile model, selected cluster model, profile feature
  table, summary JSON, and all six requested figures under
  `artifacts/runs/ef07_acceptance/profiles/`.

These values are synthetic pipeline-validation results, not findings about
real students.
