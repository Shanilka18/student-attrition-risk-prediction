# EF-06 Phase Report: Feature Pipelines and Evaluation Splits

## Outcome

The EFI preprocessing workflow now creates reusable, fold-fitted feature sets
and evaluation splits for generated sample data or configured survey data. The
work remains on `environmental-chamodya`; no merge to `main` was performed.

## Work completed

- Added stratified participant-level 70/15/15 outer splits and shared repeated
  stratified CV folds (5x3 for at least 500 train-plus-validation students,
  otherwise 5x5 with a warning).
- Saved run-specific split positions once. Added guarded single-use final test
  evaluation, with a test that ensures only the final evaluator reads the
  persisted test positions.
- Added fold-fitted imputation, pressure-aware item encoding, nominal
  one-hot/pressure encoding, and preservation of structural N/A and quality
  flags.
- Added the four schema-defined condition indices, overall pressure,
  high-pressure index count, midpoint-based travel ratio, and three configured
  interactions.
- Added configured `raw`, `agg`, `agg_profiles`, and `single_signal` feature
  sets, fold-local profile clustering, near-constant filtering, and
  model-family-driven scaling.
- Added effect-size, Spearman, mutual-information, leakage, linear-model VIF,
  and repeated-fold model diagnostics. VIF is report-only.
- Documented formulas, an illustrative example, split-first rationale,
  leakage controls, CV design, and feature-set meanings in
  `docs/05_preprocessing_features.md`.

The four profile-membership features currently use fold-fitted four-cluster
KMeans on the four indices. This is a provisional feature path; it does not
consume an external EF-7 profile artifact.
