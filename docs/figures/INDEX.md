# Publication Figures Index and Style Guide

## Visual Identity and Color Palette (§10 of PROJECT_BRIEF.md)
All figures generated by this project adhere to standard publication aesthetics:
- **Paper**: `#F5F2EC`
- **Surface**: `#FFFFFF`
- **Ink**: `#1A1D21`
- **Muted**: `#5B6168`
- **Line**: `#DDD8CE`
- **Primary Forest**: `#1F4E46`
- **Info Blue**: `#2B5C8A`
- **Warning Amber**: `#C98A00`
- **Risk Low**: `#2E7D4F`
- **Risk Moderate**: `#C98A00`
- **Risk High**: `#B3261E`
- **Extra Categorical**: `#8C4A3B`, `#6E7F3F`, `#7A6F63`

## Specifications
- Formats: High-resolution raster (300-dpi PNG) and vector (SVG).
- Typography: Clean sans-serif with readable font sizing (minimum 10 pt on tick labels, 12 pt on axes, 14 pt on titles).
- Layout: Axes explicitly labeled with units; bounding spines muted (`#DDD8CE`).
